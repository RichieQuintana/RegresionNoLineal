Analisis tecnico

El modelo predice bien los precios (R²=0.87, error mas o menos 28,500) y mantiene consistencia en validación. 
Calidad, tamaño y garaje son claves. Falla un poco en casas de lujo. 
Se sugiere usar log(precio) y ajustar hiperparámetros.
